# PALT Now Playing (browser extension)

Netflix doesn't tell the browser what is playing, so PALT and the desktop's
media controls only see "Netflix". This extension reads the show and episode
from the Netflix player and hands them to the browser.

## Install (Edge or Chrome)

1. Open `edge://extensions` (or `chrome://extensions`).
2. Turn on **Developer mode**.
3. **Load unpacked** → pick this `browser-extension` folder.

Netflix only shows the title while the player controls are visible, so the
name appears the first time you move the mouse over the video.
